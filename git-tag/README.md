# Tagging of the commits

## セットアップ

1. `source setup.sh`（または PowerShell の場合は `.\setup.ps1`）を実行する

## モチベーション

タグには注釈付きタグと注釈なしタグの 2 種類がある。注釈付きタグは名前に加えてログ出力などの情報を含むことができる。注釈なしタグは単にコミットにタグ名称を付けるだけになり、
`git show <tag>` は該当するコミットの情報が表示されるだけとなってしまう。

基本的には注釈付きタグを用いタグを付けた時点でのアップデート内容などを記載する。

## タスク

単純化のためここでは master ブランチのみを扱う。いくつかのタグはすでに作成されている。

1. 作成されたタグを確認する
2. 新しいコミットを行い新しい注釈付きタグを導入する
3. いくつかのコミットを行った任意のコミットにタグを追加できるか
4. 演習用リポジトリには注釈付きタグが含まれているそのメッセージは何か
5. 必要のないタグもあるかもしれないいくつか削除する

## 便利なコマンド

- `git tag <tag>`
- `git tag -a <tag>`
- `git tag -d <tag>`
- `git tag --list <pattern>`
- `git push --tags <branch>`
- `git rev-parse <tag>`
- `git show <tag>`
