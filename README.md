# Git 学習用コンテンツ

## 環境構築

### ローカル環境で使用する場合

![クイックスタート](/images/quickstart.gif)

1. リポジトリをクローンする
2. 解きたい練習問題のフォルダへ移動する
3. `setup.sh` スクリプトを実行する
4. そのフォルダ内の `README.md` を読んで演習の説明を確認する

## 概要

このリポジトリは Git の演習問題を集めたものです。  
`basic` から始まる演習は初心者向けでそれ以外の演習の難易度はさまざまです。
演習の一覧については [Overview.md](Overview.md) を参照してください。
